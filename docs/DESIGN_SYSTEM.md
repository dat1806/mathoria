# Visual & UX Design System

## 1. Art direction
**Cozy Fantasy 2D**.

Desired feeling:
- warm;
- safe;
- playful;
- magical;
- friendly;
- optimistic.

The world should feel like a place the child wants to return to and gradually improve.

## 2. Environment
Use soft, welcoming fantasy environments: forests, dirt paths, wooden homes, farms, flowers, mushrooms, clouds, water, and eventually magical village/castle elements.

World growth is a primary visual reward. A sparse camp should visibly become busier and more alive as progress occurs.

## 3. Characters
- rounded, readable silhouettes;
- expressive faces;
- cute proportions;
- friendly poses;
- clear emotional reactions;
- avoid excessive detail that makes small-screen reading difficult.

Hero + Guide should be visually recognizable at a glance.

## 4. Monsters
Monsters are cute, mischievous fantasy creatures rather than frightening villains.
- rounded shapes;
- humorous expressions;
- no realistic violence;
- defeat can mean dizzy/run away/calm down rather than injury.

## 5. UI principles
- Game world first; interface second.
- Avoid SaaS/dashboard aesthetics.
- Large interactive targets.
- Rounded panels/buttons.
- Large, highly legible numbers.
- Minimal text.
- Prefer icons, character reactions, and animation to explanations.
- Avoid dense navigation bars and nested menus for children.

The home world itself acts as navigation: Farm opens farming, Adventure opens the map, etc.

## 6. Learning UI
Math should remain visually inside the game scene whenever practical. Avoid switching to a sterile white quiz page.

Examples:
- answer options can be mushrooms, wooden signs, stones, cards, or other scene-consistent objects;
- visual groups use the same cozy item language as the world (carrots, apples, logs, plants);
- hints are delivered by the Guide in context.

## 7. Motion
Preferred motion language:
- bounce;
- pop;
- float;
- wiggle;
- gentle shake;
- small scale changes;
- resource items flying into inventory;
- satisfying building construction/reveal.

Ambient life can include NPC walking, animals moving, crops swaying, clouds drifting, and the Guide following the Hero.

## 8. Wrong-answer feedback
Avoid aggressive red failure screens. Use gentle visual feedback and immediately shift into explanation/support.

## 9. Progressive disclosure
Do not expose every system at once. The first experience progressively introduces map, gathering, NPCs, battle, rewards, and building.

## 10. Responsive direction
Primary prototype can prioritize desktop/tablet browser layouts while keeping touch-friendly controls and responsive structure. Do not depend on hover-only interactions.
