# Implementation Phases

Recommended implementation order:

1. **Foundation** — React/TypeScript project structure, generic math/content domain, state, persistence, basic routing/scenes.
2. **Tutorial** — beginner multiplication introduction, visual groups, construction, Guide hints.
3. **Camp** — cozy home scene, Hero/Guide placeholders, Adventure entry, persistent world state.
4. **Adventure** — Forest path, gathering, Farmer quest, rewards.
5. **Battle** — Slime battle, varied question representations, wrong-answer support.
6. **Building** — Farm construction, resource spending, permanent world change, farming activity.
7. **Deep Forest & Mini Boss** — second short adventure and Big Slime culmination.
8. **Polish & Playtest** — animation, sound where useful, responsive/touch UX, balancing, instrumentation if later approved.

Create a detailed phase specification immediately before implementing that phase so decisions can reflect what was learned from the previous phase.
